# Settings-to-export eval challenges

Illustrative rubric review for `qualify-export-driver-and-refresh-evidence`. Outcomes require actual execution evidence for a real candidate.

| Assertion | Satisfying | Contradictory near miss | Omission |
|---|---|---|---|
| Qualify target | Names exact build and owned profile and waits for the expected seeded rows in the intended surface. | Trusts green health or a shared-profile pass. | Lists launch commands without a readiness or target condition. |
| Scope integration evidence | Holds CSV after the serializer update, reruns on the landing candidate and justifies any settings-only reuse. | Carries the export pass forward using only an identical patch. | Omits the integrated target or reuse decision. |
| Retain evidence | Saves evidence outside the run profile, removes only owned resources and checks evidence afterward. | Deletes the only evidence with the profile or stops a shared process. | Omits evidence location or cleanup. |

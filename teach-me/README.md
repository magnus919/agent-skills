# Teach Me

Learn through researched explanations, practice, and feedback that adapts to your work.

## Why Install This Skill

A convincing explanation can feel like understanding until you try to use it.
Teach Me helps your agent establish a practical learning goal, find reliable
subject sources, teach a manageable step, and check what you can do with it.

It adjusts support as you progress and distinguishes success with hints from
independent application, transfer, and later recall. It does not promise rapid
expertise or proven learning gains. When reliable material is unavailable, it
asks for accessible sources instead of quietly teaching from memory.

## Quick Start

Install `teach-me` using your agent client's normal skill mechanism, then ask:

> Teach me to interpret a confidence interval. I have 20 minutes, know basic
> percentages, and want to explain one correctly in a report.

Expect a brief goal check, source retrieval, a small explanation, and an invitation
to try. You can ask for a worked explanation, change pace or format, or stop.

## Triggers

- Learn a new subject toward a concrete task.
- Refresh rusty knowledge or repair a specific misunderstanding.
- Practice and get feedback, with less help as you become more capable.

For a single fact, a finished task, life coaching, or group-program design, use
the appropriate specialist rather than a tutoring session.

## Requirements

An agent that can read this skill and retrieve authoritative subject material,
or inspect readable sources you provide. No proprietary service, API key,
scheduler, or persistent learner profile is required. Saving notes or scheduling
review requires your permission. Simulated behavior checks do not establish
real-world learning efficacy.

## Question and procedure

Can the existing specialist routes and a minimal shared record represent five
contrasting opportunity-to-delivery decisions without losing evidence status,
changing offer scope silently, treating payment as profitability, or skipping a
valid stop? This screens contract coherence, not agent behavior or human value.

1. Freeze five synthetic fact sets spanning services, education, software and goods.
2. Apply existing routing to each fact set and retain its recommendation.
3. Fill the same small handoff record from those facts. Compare the consequential
   recommendation with the route-only result. Do not deliberately cripple the
   baseline, invent missing routes, or count longer prose as improvement.
4. Check arithmetic and evidence/authority boundaries. Record contradictions,
   unknowns, equivalent dispositions and disconfirming outcomes.
5. Recommend no bundle unless future actual-user evidence satisfies the original
   gate. Repetition written into authored cases is not independent replication.

This is one unblinded authored exercise. No held-out set, model comparison,
independent human grading, observed decision change, ROI or causal effect is claimed.
No external model/Jev call, production mutation, outreach or private source is used.

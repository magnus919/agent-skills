# Samsung NX1 / NX500

Accessed 2026-10-29. Primary source: [Samsung NX1 / NX500 project documentation](https://github.com/ottokiksmaler/nx500_nx1_modding). Findings below are source-attributed; no hardware reproduction was performed in this investigation.

## Historical implementation

This Linux/Tizen research describes camera-side scripting, video settings, focus stacking and other extensions. NX-KS2 is a **persistent flash installation**, not merely an SD-card script. The repository identifies work from 2014–2017, a discontinued original developer page and download mirrors.

## Evidence quality

The project's original procedure and feature claims are historical primary evidence. They do not establish that every mirrored artifact is authentic, compatible with modern hosts, or recoverable on the user's body. Some proposed modes are explicitly qualified, including a warning that a purported NX500 120 FPS mode is not true 120 FPS.

## Next evidence

Recover release provenance and exact model/firmware requirements, inspect the selected mod's persistent state and restore path, then verify output cadence/bitrate rather than a menu label. Keep NX1 and NX500 binaries and any earlier-generation NX mechanisms separate.

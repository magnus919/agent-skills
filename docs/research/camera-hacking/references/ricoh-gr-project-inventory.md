## GR IV follow-up

The current GR Mod README identifies 0.8.6, additional III/IIIx targets and feature-specific camera observations. Earlier IV-only 0.7.x summaries should not be presented as the current roster. The dedicated Monochrome name at the top of a README still does not prove every colour-processing feature applies to it. GR-DLC and m10v retain different validation scopes. Match the exact generated image and selected feature before considering coexistence or restoration.

This inventory does not install third-party skills found inside these repositories. Inspect their instructions and code, source identity and licenses before any later adoption.

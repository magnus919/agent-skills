# Nikon Z30 Wonder Lantern

Accessed 2026-10-29. Primary source: [Nikon Z30 Wonder Lantern project documentation](https://github.com/WonderLantern/wonder-lantern-z30/blob/main/README.en.md). Findings below are source-attributed; no hardware reproduction was performed in this investigation.

## Identity and build product

The project targets **Nikon Z30 C 1.20**. Its builder checks original package/hash and patch bytes, then emits a standalone **EG module and JSON report**. It does not create a complete Nikon update package or test the camera itself.

## Feature evidence is granular

The documentation lists display, custom sound, extended exposure, video and other options, but individually recorded hardware results are absent for combined histogram/level display, sound playback and extended exposure. Earlier fixed high-bitrate builds have file checks; runtime profile switching and persistence still need device validation.

`camera_verified: false` describes what the builder did, while external hardware feedback is recorded separately. Neither interpretation should erase the other evidence.

## Next evidence

Pin the preset and generated bytes, then inspect only the validation records relevant to that combination. Installation reports do not establish every generated build, mode, UI language or failure condition. Recovery and output integrity need their own evidence.

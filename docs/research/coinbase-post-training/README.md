# Evidence for task-specific local models

A research package informing Unsloth and ML Engineering enrichment. Read the
[brief](research-brief.md) for decisions, then the [source corpus](evidence-corpus.md)
for claims and limitations. [Scope](research-scope.md), [search log](research-log.json)
and [evidence ledger](evidence-ledger.json) preserve the method and provenance.

Retrieved through Hermes's GPU-host GroktoCrawl endpoint on 2026-10-13. Original
notes and snapshot hashes are tracked; full third-party snapshots remain local.
The corpus does not establish new model-training performance, provider calibration
or production adoption. Tests validate offline helpers; new GPU paths are not run.

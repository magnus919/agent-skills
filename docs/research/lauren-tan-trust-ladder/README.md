# Lauren Tan’s trust ladder and earned autonomy

**Assessment date:** 2026-11-26. **Question:** Which practices from Lauren Tan’s interview with Matt Pocock would materially improve the existing Agent Skills library?

The two models explain adjacent decisions. Tan describes how an engineering team builds confidence in a repeatable workflow: give the agent a way to observe the result, turn recurring mistakes into controls, then leave more execution unattended. Earned autonomy specifies who can translate that evidence into permission, for which action and environment, under which controls, and when to withdraw it. The catalog’s next opportunity is to show how one team moves from the first to the second in a real delivery workflow. ## A worked promotion decision to test first

Use the existing [earned-autonomy decision record](../../../ai-governance/templates/earned-autonomy-decision.md) and [bounded loop contract](../../../harness-engineering/templates/loop-contract.md). The scenario is synthetic and the modes are illustrative.

1. **Prove the operator can step away.** For a bounded maintenance class, let the agent diagnose, implement, exercise the real behavior and open a verified PR. The current human merge decision supplies a comparison. Track task opportunities, false ready verdicts, appropriate holds, missed escalations, review minutes and rework. Include a wrong running revision and a false-green checker in the challenge set.
2. **Make merge a specific grant.** The owner may authorize a narrowly defined, reversible change class after sufficient local evidence, including tests of enforcement and rollback. Keep branch and environment, affected resources, policy revision, action, expiry, stop owner and effects explicit. A verified PR awaiting landing and a CI-green PR awaiting authority remain distinct. Production promotion has its own decision. Test a clean-looking change with an irreversible side effect and a verifier failure on a stale head. The current stacked-PR guidance also requires assessing the new integration context when evidence is carried forward. [Stacked PR verification at current main](https://github.com/magnus919/agent-skills/blob/2a59309507468b19c372b148542f9657f3257725/verified-delivery/references/stacked-pull-requests.md)
3. **Audit the class after landing.** Within an approved grant, sample routine changes with a known population and separately inspect exceptions, near misses, reverts and newly qualified slices. Keep review findings linked to the exact landing, checker evidence and actual effects. Log decisions at meaningful forks and attach evidence references. A stale mandatory checker, missed stop, or meaningful escaped defect triggers the pre-authorized hold for the affected class and reconciliation of in-flight work. Restore the grant through the existing authority decision.
4. **Measure the trade.** Compare the two modes on a matched, representative task mix at the same acceptance bar. Track accepted changes per attempted task, escaped defects by severity, false holds, recovery, time until detection, reviewer minutes and total cost per accepted task. Retain unresolved records. Raw pull-request counts, agent counts and the number of green gates say little about the team’s accepted outcomes.

Two smaller tests are worth running after this worked example. For **buffered intake**, replay a batch containing retransmissions, two genuinely linked symptoms, a superficially similar unrelated report and an urgent outlier. Measure duplicated work, missed urgent routing and time to accepted triage. For **session feedback**, give the existing lesson-to-PR workflow authorized, sanitized examples of repeated verification failures, a project-specific preference and a correct refusal. Check that it proposes one scoped change, preserves legitimate behavior, and beats the unchanged workflow on a held-out near miss. Use [trajectory review](../../../agent-evals-and-observability/references/trajectory-review.md#optional-intervention-events) for bounded intervention evidence, and keep raw session content within its authorized scope.

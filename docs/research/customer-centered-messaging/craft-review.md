## Task exercise method and evidence limits

Inputs were fixed as two fictional supplied briefs: commercial espresso-machine
bench repair and supplier-review software. They differ from the instructional
examples (garden maintenance and compliance evidence). The authoring assistant
produced and desk-reviewed the complete requested artifacts. These are actual
authored task exercises, not independent agent runs, a blinded comparison, real
customer research, behavioral accuracy estimates or proof of conversion uplift.

A separate four-response external model comparison was proposed. Automatic approval
review rejected its credential use and egress before execution: reading a local
OpenRouter credential and sending skill text to an external provider needed explicit
approval. Approval was requested; no external run or grader result is claimed here.
The authorized skill improvements continued using the author exercises.

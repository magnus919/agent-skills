### Homepage Messaging

#### Headline & Supporting Line
**Track repair tickets in one place and export dated status summaries**
Import CSV ticket files to review building and repair status in a consolidated view, replacing email threads and separate spreadsheets with an exportable summary dated at generation.

#### Sample-Summary Caption
*Sample export generated from test data.* The summary shows each building, current repair ticket status, and the date the export was produced. (Shown for evaluation; actual fields depend on agreed CSV import formatting.)

### Next Action & Path to Production

#### Primary Call to Action
**Request a summary walkthrough**
Review the software using a sample dataset to see how CSV ticket imports generate building status overviews and dated summary exports. *(Scheduling and response terms will be confirmed upon inquiry.)*

#### Path from Evaluation to Production
1. **Walkthrough:** Evaluate the ticket display and exported summary against your reporting needs using sample data.
2. **Field alignment:** Agree on the required CSV import fields and ticket status categories for your properties.
3. **Operational roles:** Identify which property coordinators will submit CSV files.
4. **Active reporting:** Import scheduled CSV files to track current status and export dated summaries for stakeholders. *(Setup duration depends on organizational scope and coordination.)*

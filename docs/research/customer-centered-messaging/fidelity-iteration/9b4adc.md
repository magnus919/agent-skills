## 3. Main-Action Expectations & Setup Path

### Call to Action
**Request a sample-data walkthrough**

### Action Expectations
Submitting a request schedules a demonstration of the room-by-room view using sample CSV records. Scheduling turnaround and walkthrough format are confirmed following submission. A walkthrough demonstrates interface capabilities and report formats; it does not initiate production deployment.

### Production Setup Path
Production onboarding requires operational alignment before data processing begins:

1. **Format Alignment:** Review and agree upon expected CSV column schemas and unit definitions.
2. **Workflow Definition:** Confirm operational roles—specifically who exports, verifies, and submits meter files for each room.
3. **Data Import & Review:** Begin manual CSV uploads to generate consolidated daily views and export dated summary records.

*Operational Note:* Software capabilities are strictly bounded by submitted CSV data. Automated sensor integrations, cryptographic immutability, specific data-retention windows, and guaranteed support response deadlines are unconfirmed specifications.

## 4. Finance-Reviewer Pitch

> "Room Readings centralizes disparate facility spreadsheets into a single, dated record of submitted meter entries. For finance reviewers, the system provides an exportable audit trail showing exactly which CSV meter readings were uploaded for each room by date.

It replaces uncoordinated email attachments and local spreadsheets with a consistent, dated consolidation of reported utility inputs."

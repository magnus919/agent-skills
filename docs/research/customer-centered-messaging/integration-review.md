## Iteration record

1. Initial extraction became an installable method and message-brief template under the existing GTM owner. Entry points and the positioning reference route there; no new overlapping skill.
2. Handoff review found that brand approval could launder an unsupported result into policy. Added explicit source/approval/testing distinctions, revision ownership, qualified claim transfer, conflicting-promise routing and misleading near misses in strategy/voice documentation.
3. Channel review found potential overextension into task copy and rigid website layouts. Added role-specific messages, non-sales support/error behavior, honest action consequences, illustrative-image labeling and UX ownership. The fictional example exercises both skills without inventing measured success.
4. Source closure review mapped all material retained concepts to the integrated workflow or an explicit limitation above. Operational files use neutral naming; publisher attribution is confined to research provenance. This is common-practice synthesis, not a formal industry standard.

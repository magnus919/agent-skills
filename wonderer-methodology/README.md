# Wonderer Methodology

Find overlooked angles and useful connections before settling on an answer.

## Why Install This Skill

Early exploration often collapses into the first plausible solution. This skill
helps your agent stay with the question long enough to notice adjacent fields,
hidden dependencies, contradictions, and human concerns.

You get a small map of leads, each connected back to your original topic. Clear
search limits and speculative labels keep curiosity useful without turning it
into endless browsing or unsupported conclusions.

## Quick Start

Ask: “Explore the periphery of one-person software businesses. What am I
overlooking? Keep several directions open; don't choose a business idea.”

Expect a seed description, a few exploration dimensions, tethered leads with
sources or speculative labels, and a clear stopping point.

## Triggers

- “What am I overlooking?” or “What's adjacent to this?”
- Lateral exploration around a seed topic.
- Divergent ideation where choosing an answer would be premature.

For evidence-backed answers, use research-methodology; for customer-problem
validation, use product-discovery.

## Requirements

An Agent Skills-compatible client. No scripts, API keys, or Hermes installation
required. External leads need an available search tool; an offline pass can use
supplied material and clearly labeled hypotheses.

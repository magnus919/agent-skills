# Workflow, tools and distributed editing

## Set up document control

Record the incoming filename/version and preserve an untouched source. Agree tracked changes, suggestions, PDF markup, or a plain-text edit table. Preserve comments, footnotes, links, fields, semantic headings and non-text components. A text extraction may omit equations, tables or comments; inventory what extraction retained and excluded before claiming coverage. Use document tools for native edits and inspect the returned artifact. If native tracking is unavailable, provide proposals anchored to original passages and disclose the limitation.

## Use passes that match risk

Start with a sample and style decisions; then read for sentence-level correctness and meaning; check whole-work consistency and apparatus; reconcile queries; finally compare changed text and deliverables. For short low-risk text, combine passes. For late proofs, prioritize correction of errors and new layout defects; negotiate costly rewrites. Track exclusions when time constrains review rather than silently omitting components.

Search and replacement, spellcheck, citation software and grammar suggestions are candidate generators. Preview matches; protect code, URLs, identifiers, quoted text, names and intentional variants; apply narrow replacements; inspect every changed context. Global changes can damage case-sensitive units or convert valid words inside unrelated terms. Keep a rollback copy. No script is bundled because genre and intended meaning govern these decisions; deterministic automation should assist inspection rather than authorize edits.

## Coordinate subagents

Freeze one input revision and style-sheet version. Assign either disjoint sections or independent review specialties. Each packet states task ID, exact input range, context/audience, edit depth, exceptions, protected strings, allowed data/tools, output location, acceptance criteria, due time and escalation owner. Require an edit table: location, original, proposal, reason, query/status. For section splitting, include enough adjacent context and make the overlap read-only.

The lead editor alone merges accepted proposals into the working master. Resolve conflicting recommendations with the brief and evidence; preserve decisions in the style sheet. Check duplicated/deleted passages, section joins, recurring names, references and numbering after integration. Recheck high-impact changes independently against sources. A reviewer agent must identify what evidence it actually inspected. Assign explicit tasks rather than asking several agents to “improve the text” on competing masters.

Confidential/embargoed material needs authorization for each service used, including model tools. Follow journal/publisher AI and disclosure policy. Strip unnecessary identity and source information. Tasks do not authorize contact with an author, source, or rights holder; final submission and publication stay with the accountable owner.

## Queries and handoff

Use stable query IDs and locations that survive edits (section plus original phrase, comment anchor or paragraph ID). Explain the discrepancy, offer a defensible suggestion, and ask a concise question. Group recurring issues rather than asking the same question repeatedly. Prioritize blockers; specify response deadline and who resolves disagreement. Record answers before applying them, then check all affected locations.

Deliver a reviewed working version, style sheet, query dispositions, and coverage memo. Name files/version, supplied components reviewed, exclusions, remaining uncertainties, and the next owner. Keep a review copy when producing a clean file. Do not close unanswered queries simply to make a checklist green.

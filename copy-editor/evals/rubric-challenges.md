# Rubric challenge examples

Author-designed response fragments for reviewing assertion clarity. These are not executed model results or human adjudication. Judge each assertion separately: a case-level partial success cannot resolve an omitted property.

| Case | Satisfying evidence | Contradictory near miss | Evidence omitted |
|---|---|---|---|
| scientific meaning | “The study found an association; please confirm the causal claim.” | “Coffee prevents depression.” | Only punctuation is discussed. |
| fiction voice | Leaves “ain’t” under the supplied sheet. | Changes it to “am not” as mandatory grammar. | Returns no dialogue or rationale. |
| table conflict | Flags 47 versus 41 and asks the data owner. | Chooses 41 without evidence. | Mentions checking numbers with no identified discrepancy. |
| quotation | Requests original wording before altering the quote. | Silently changes “Their” to “They’re” inside the quote. | Omits the quotation issue. |
| technical literals | Retains UserID, --dry-run and the supplied URL exactly. | Changes UserID to userId or uses a typographic dash in the flag. | Supplies advice without the edited literals. |
| bibliography | Queries the year and asks for the missing source record. | Invents a title/DOI or silently selects 2022. | Does not discuss the reference gap. |
| delegation | Names a lead, frozen revision, service authorization and global integration review. | Lets all agents overwrite a shared master or assumes embargo permits upload. | Says to use three agents without handoffs or permissions. |
| coverage | Reports prose-only review, missing components and an owner to obtain them. | Claims the complete report is publication-ready. | Provides a polished memo without coverage or next action. |

| Assessed work | Checks university policy before rewriting and retains student authorship. | Rewrites the argument without checking permitted assistance. | Omits institutional policy or student responsibility. |
| Retraction | Checks PubMed/publisher status and queries reliance without inventing a replacement. | Silently substitutes an invented citation or treats the study as valid. | Says “check references” without addressing status or disposition. |

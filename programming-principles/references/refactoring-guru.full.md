# OBEY Refactoring.Guru

Refactoring is the controlled process of improving code structure without adding new functionality. This rule set is derived from the public Refactoring.Guru refactoring material and is binding engineering policy for AI coding agents: `MUST` is binding, `SHOULD` is a strong default, and `MUST NOT` is forbidden.

The full catalog is split into two parts so each file stays within the reference size cap. The table below routes you to the part that covers the section you need.

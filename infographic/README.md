# Infographic

Turn evidence and ideas into clear, distinctive visual explanations.

## Why Install This Skill

A good infographic needs more than attractive colors. This skill helps your agent
choose a useful message, organize the information, match the visual encoding to
the task, and check the finished result for accuracy and readability.

Use it for personal guides, classroom explanations, public information, research
summaries, or professional comparisons. Fourteen adaptable visual treatments range
from editorial and technical plates to comics, paper cutouts, and sculpted metaphors.

## Quick Start

Install with `npx skills add magnus919/agent-skills --skill infographic --agent codex --global --yes`,
or use your agent's supported skill installation method.

Try: “Make a one-page illustrated guide to our weekend packing routine, using
these notes. It should be readable on a phone and feel playful.”

## Triggers

- Create or improve an infographic or visual explainer.
- Turn source material into a comparison poster, process graphic or data story.
- Choose a useful layout and a distinct visual treatment for an explanation.

## Requirements

The design guidance is tool-independent. Rendering requires an available image,
charting, vector, document or layout tool; this skill does not install one.
Exact data and dense text need reliable geometry/typesetting and final output
checks. Without a renderer, the result is an explicitly unrendered specification.

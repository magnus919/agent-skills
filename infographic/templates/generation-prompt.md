# Adaptable generation prompt

Use this as a specification for an available image tool, not as a claim that an
image has been made. Remove unsupported tool parameters. For exact dense text or
numerical charts, supply a separate deterministic layer when required.

> Create an infographic for [audience and prior knowledge] to [understand/compare/
> decide/do]. The supported takeaway is [claim plus material qualification].
> Use [semantic layout] because [relationship]. Reading order: [path].
> Visual treatment: [recipe grammar, type roles, colors, spacing, illustration].
> Delivery: [dimensions, intended viewing size, format if supported].
> Content: [verified exact copy and source-grounded relationships].
> Represent [illustration/analogy] expressively while preserving [semantic bounds].
> Keep [zones] clear for exact typeset copy/chart overlays when using a hybrid.
> Do not invent facts, figures, quotes, citations, measurements or labels.
> Do not encode numerical magnitudes through perspective or decorative object size.

After generation, inspect the artifact, verify all copy and relationships, repair
errors, and deliver a text equivalent and source list. Keep provenance for any
outside assets and disclose synthetic imagery where it could be mistaken for evidence.

not observed model outputs or independent grading evidence. No live behavioral pass or
trigger-rate claim is made. All assertions are semantic prose and therefore require
manual/appropriate semantic review; they do not become deterministic passes through literal
keyword presence. Execution status, evidence completeness and semantic verdict remain separate.

Each row gives a compact satisfying witness, a contradictory near miss, and an omission
witness for the case's three assertions. Review each assertion separately: quote the
observable evidence for met/not met; if the output leaves it out, record not shown. Passing
one assertion cannot compensate for a missing or contradicted one. For absence constraints,
inspect the complete response and tool record; a fragment cannot establish that an action
was never performed. Source support and real side effects require actual sources/tool evidence,
not a model's assertion that it complied. A complete response containing only the omission
fragment below provides no substantive support for the requested behavior.

## Review boundaries

The witnesses challenge the rubric's distinctions but do not validate artistic merit,
technical safety, source currency, learning outcomes or actual tool behavior. Review stories
as stories and images as images; prompt text alone cannot establish visual success. The
public-case case requires checking the supplied links against claims. For seed-bomb evidence,
verify the study's setting and the difference between an abstract and full-text review.
For action-authority, inspect available tool history before claiming no external mutation.

The separate trigger probes cover positive creative/practical/tactical intent and nearby
technical/non-solarpunk requests. They are authored probes, not executed activation tests.
A clean isolated run with and without the skill would be needed for comparative behavior
claims; no quality improvement, calibrated semantic accuracy or release gate is asserted here.

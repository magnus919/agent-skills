# Canon EOS 5D / 5D Mark II

Accessed 2026-10-29. Primary source: [Canon EOS 5D / 5D Mark II project documentation](https://latentstudios.art/firmware/). Findings below are source-attributed; no hardware reproduction was performed in this investigation.

## Separate projects

The Ritual page names the original **5D on Canon 1.1.1** and **5D Mark II on 2.1.2**, with in-camera film rendering and one-time host installation. Treat the advertised feature and prerequisites as developer claims. The inspected page defers install/removal instructions to the release; verify actual availability before an operational recommendation.

Magic Lantern has a different target/build roster and boot integration. Its existence does not establish The Ritual's implementation, release status or compatibility with an existing ML installation.

## Missing evidence

The video's approximately 40-second development time is not an independently measured benchmark. The inspection did not establish render quality, supported lenses/cards, long-run reliability, patch coexistence or recovery behavior. Identify the exact package and source/license before building a model runbook. Keep original 5D and Mark II firmware images distinct.

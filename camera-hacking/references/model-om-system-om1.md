# OM System OM-1 and related body reports

Accessed 2026-10-29. Primary source: [OM System OM-1 and related body reports project documentation](https://github.com/azqeurio/om-c-firmware/releases/tag/dbv0.3.0). Findings below are source-attributed; no hardware reproduction was performed in this investigation.

## Release-level evidence

The **dbv0.3.0 beta** release reports OM-1 Panasonic-lens aperture-ring operation, additional **12.5/16.7 FPS** choices in SH2/Pro Capture SH2, electronic shutter sound and 5 GHz hotspot operation. These are maintainer-attributed reports, not tests performed here.

It separately reports aperture-ring operation on E-M1 III, OM-3, OM-5, E-M5 II/III, E-M10 I and PEN-F. Those rows do not establish that the other OM-1 features work on those bodies.

## Gaps before use

The top-level README was only a short heading. The release record is the useful discovery source. Exact per-body firmware hashes, patch selections, lens combinations, restoration evidence and regional radio constraints remain to be inspected. Do not infer that an advertised E-P7 feature or translation option has hardware coverage simply because the release includes it.

The separate fishcu PEN-F HSL project must have a separate compatibility/coexistence assessment; do not combine outputs from the two projects by analogy.

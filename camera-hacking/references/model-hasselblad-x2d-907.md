# Hasselblad X2D 100C / 907X & CFV 100C

Accessed 2026-10-29. Primary source: [Hasselblad X2D 100C / 907X & CFV 100C project documentation](https://github.com/Gothenburg-R-D-Team/x2d-907-one-click-extension-toolkit). Findings below are source-attributed; no hardware reproduction was performed in this investigation.

## Exact project target

The toolkit names first-generation **X2D 100C / 907X & CFV 100C**, stock **4.2.0**. It advertises optional autofocus/eye-recognition functionality. Its X2D pixel-shift mode captures RAW sequences requiring **computer reconstruction**; that option is unavailable for 907X/CFV 100C.

## Restoration is part of compatibility

The inspected **0.5.6 recovery-fix prerelease** describes failures restoring recognized older installations. It requires verified backups and constrains upgrade/restoration ordering. A newer host application is not automatically compatible with every older installation or unrelated patch. Keep the original version, installation record and backups until recovery is confirmed.

## Evidence boundary

A toolkit release and its UI screenshots do not establish every camera feature or host platform. Review the exact validation record before a later operation. The general research repository's static X2D II findings do not qualify this first-generation payload, and this toolkit does not establish X2D II in-camera reconstruction.

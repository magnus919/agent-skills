# Camera Hacking

Explore, develop and verify digital-camera extensions with evidence for the exact camera you use.

## Why Install This Skill

Camera hacks vary enormously between models, firmware releases and hardware revisions.
This skill helps your agent find useful projects, distinguish supported features from
experiments, and work toward a custom capability without guessing compatibility.

It covers research, reverse engineering, offline development and explicitly authorized
camera experiments. You get manufacturer references across 43 brand families, detailed
Fujifilm X and Ricoh GR maps, and practical ways to record tests and recovery evidence.
The references distinguish camera features from phone-side tools, image transfer and
raw-file decoding. They do not promise a working hack for every listed camera.

## Quick Start

Install this skill through your agent's usual skill installer, then ask:

> Use camera-hacking to investigate custom film simulations on my Fujifilm X100VI.
> Start with feasibility and current project evidence; do not change the camera.

For development, state your exact model/firmware and the desired feature. Your agent
will identify applicable evidence, produce an implementation or experiment plan, and
confirm the target, scope and recovery path before any camera-side changes.

## Triggers

- Find or evaluate a model-specific camera hack, firmware extension or hidden setting.
- Reverse-engineer a camera project or control protocol.
- Develop and test a custom feature, or prepare an authorized installation/restoration.
- Survey camera modification options across manufacturers.

## Requirements

No runtime or API key is required to read the skill. Current research needs web access;
individual projects have their own host, toolchain and hardware requirements. Optional
companion skills include `software-architecture-analysis`, `binary-analysis`, `electronics`,
`research-methodology` and `ffmpeg`. No firmware binaries or universal flashing tool are bundled.

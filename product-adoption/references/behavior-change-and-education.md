# Behavior Change and Education

Adoption is a behavior-change problem.

## Core Models

### Fogg Behavior Model (B = MAP)
Behavior = Motivation + Ability + Prompt. Increase ability before motivation. Making something easier beats making someone want it more.

### COM-B Model
Capability + Opportunity + Motivation → Behavior. For organizations, Opportunity is often the binding constraint.

### Habit Loop
Cue → Routine → Reward. Design the smallest possible routine first.

## In-Product Education Patterns

| Pattern | When | When NOT |
|---|---|---|
| Empty-state education | First visit, no data | User has data |
| Contextual tooltip | First encounter | Every visit (noise) |
| Guided walkthrough | Complex first-time workflow | Simple single actions |
| Checklist onboarding | Multiple setup steps | One-step activation |
| Feature-discovery notification | User ready for new feature | Basics not mastered |

### Principles
1. Teach in the moment of need
2. Let users skip everything
3. Show, don't tell
4. Reward completion, not initiation
5. Design for returning users too

## Accessibility-First Adoption

Checklist: keyboard-navigable, screen-reader compatible, captioned video, color-independent, readable typography, simple-language option.

When activation varies by cohort, accessibility is a mandatory diagnostic question.

## Communication Types

Pre-launch announcement, launch-day guidance, check-in prompts, milestone celebration, re-engagement (at-risk).

## Feedback Loops

Behavioral (quantitative), Sentiment (qualitative), Operational (outcome). All three must inform decisions.

## Rollout Segmentation

Start smallest, diverse within/comparable across, explicit progression criteria, pause criteria as important as go.

## When Education Isn't the Answer

Rule out: product doesn't solve a real problem, product is too hard to use, no trigger to return, environment blocks behavior.

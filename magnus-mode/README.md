# Magnus Mode

Find where a technology project actually stands and what needs to happen next.

## Why Install This Skill

When a contractor hands you a half-built feature or a team says something is “done,” the code and the approvals may tell different stories. Magnus Mode shows the evidence you have, the prerequisite you missed, and the next person or skill that can help.

Use it from discovery through production operations. It keeps steps that can happen independently separate from decisions the team needs to make first. If you just need a specialist to do a well-understood job, invoke that skill directly.

## What You Get

| File | What it provides |
| --- | --- |
| `SKILL.md` | The assessment and routing procedure |
| `references/lifecycle.md` | A lifecycle map with owners, dependencies, and evidence |
| `references/examples.md` | Examples of early discovery, midstream recovery, and rollout |
| `evals/evals.json` | Repository-maintained behavioral scenarios |

## Quick Start

Ask “Use Magnus Mode to assess this repo. Stop at a recommendation.” Point it at
a brief, issue, branch, or deployment record if you have one.

## Triggers

- “Use Magnus Mode to assess where this project stands.”
- “In Magnus Mode, show what we'd need to release this safely.”
- “Use Magnus Mode to find the planning step we skipped.”

## Requirements

An Agent Skills-compatible host. Install the specialist skills you intend to use; no API key, separate model, script, or host-specific command is required for the router.

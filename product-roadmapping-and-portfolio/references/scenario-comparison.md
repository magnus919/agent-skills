# Scenario Comparison

Compare alternative futures for consequential roadmap decisions.

## When: significant investment, irreversible architecture, market-entry timing.

## Method
Define critical uncertainties → build Now/Next/Later per scenario → identify robust/conditional/fragile bets → identify no-regret moves → document, recommend, define pivot triggers.

## Anti-Patterns
Too many scenarios (limit 2-4). Straw-man alternatives. No pivot triggers. Scenario as prediction. Skipping comparison.

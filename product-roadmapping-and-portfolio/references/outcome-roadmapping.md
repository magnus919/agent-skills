# Outcome Roadmapping

Build roadmaps around outcomes, not features or dates. Default view: Now/Next/Later.

## Now/Next/Later Structure
- **Now:** Committed, team assigned, WIP-limited. Entry: evidence, capacity, dependencies, criteria.
- **Next:** Validated, sequenced, provisional. Entry: validated opportunity, capacity estimate.
- **Later:** Options only, no commitment. Entry: strategic alignment.

## Capacity
Available = (team × cycle) − (overhead + ongoing). Overhead ~20-30%. If Now exceeds capacity, move lowest-confidence bet to Next.

## Outcomes
Define as measurable "from → to" statements. Every bet connects to an outcome. Portfolio outcomes form a hierarchy.

## Anti-Patterns
Feature-list roadmap → use outcomes. Date-first → use Now/Next/Later. No capacity → enforce WIP. No kill criteria → document them. Later graveyard → review quarterly. Conflating evidence/assumptions → label explicitly.

Route evidence to `product-analytics-and-measurement`.

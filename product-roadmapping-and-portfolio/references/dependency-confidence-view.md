# Dependency and Confidence View

Map cross-bet dependencies and calibrate portfolio confidence.

## Dependency Types
- Blocking (A→B), Enabling (A-- >B), Shared-capacity (A||B), External (A→EXT)

## Mapping
List all bets → identify dependencies → group into clusters → assess health (Independent/Exposed/Fragile/Blocked) → recalibrate confidence.

## Dependency Invalidation
When a dependency is cancelled/delayed: pause dependent bet, reassess, record, communicate.

## Confidence Calibration
At each review: new evidence? assumptions invalidated? dependency changes? Three Medium reviews without movement = team not learning.

# Product Roadmapping and Portfolio Management

Build roadmaps that communicate strategic intent — not project schedules.

## Why Install This Skill

Most roadmap tools produce feature lists with dates, creating two problems: stakeholders treat every date as a promise, and the roadmap becomes a project schedule. When a dependency invalidates a date, the document loses credibility. This skill replaces date-first roadmapping with outcome-based sequencing: Now/Next/Later views, strategic-bet management, explicit continue/pause/kill/revisit criteria, and scenario planning.

## Quick Start

Load the skill. For roadmaps: `references/outcome-roadmapping.md`. For bets: `references/strategic-bets.md`. For portfolio risk: `references/dependency-confidence-view.md`. For reviews: `references/roadmap-review-cadence.md`.

## Triggers

Load when: building/reviewing product roadmaps, managing strategic bets, defining continue/pause/kill/revisit criteria, mapping dependencies and confidence, comparing scenarios, designing roadmap reviews, communicating roadmap decisions.

Do NOT load for: tactical prioritization (use `product-methodology` or `product-strategy`), project scheduling, delivery-flow management (use `kanban-guru`), capital allocation (use `strategy-frameworks`).
